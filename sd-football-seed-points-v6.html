Current seed points from games played, plus projected standings once the remaining games are decided. Click a team to see its game-by-game points.

Projected standings

“Now” uses only games already played. “Projected” adds every remaining game using the picks on the right.

Remaining games

Auto picks go to the team with more seed points (GoBound’s number when you’ve imported standings), or the better record when seed points aren’t known. Click the other team to change a pick.

Load scraper data

Load the gobound-football.json file made by the GoBoundScraper app. It replaces the teams and games you have loaded with a fresh copy. You can also drop the file anywhere on this page.

Paste from GoBound

Works with a class’s standings page, a weekly scoreboard, or a team’s schedule page. Select the games on the page, copy, and paste here. You can paste several weeks or several teams at once.

Preview

Paste games and choose Read games. Nothing is added until you confirm.

Update classes

The 2026 class list is built in. To change it, paste GoBound’s teams page (class headings are read automatically), a single class’s standings page, or team names one per line. The class below is used until a class heading appears.

Teams and games

Edit the list, then apply. Your picks are kept for games that still exist.

    Format

    Declare each team and its class on its own line:

    @team Pierre | 11AA

    For an opponent whose full schedule you aren’t entering (out-of-state, another class), add its record from games not in this list so its win percentage is right:

    @team Some MN School | Other | 4-2

    Then one game per line, away team first:

    2026-09-04, Huron, Pierre, 14, 28

    Leave the scores blank for games not yet played:

    2026-10-16, Pierre, Huron, ,

    The importer also writes two other kinds of lines. @record Yankton | 7-2 is an opponent’s current record as shown on GoBound, used when you haven’t imported that opponent’s own schedule. @alias Pierre T.F. Riggs = Pierre tells the app two spellings are the same team.

    Add nv as a sixth field for a non-varsity opponent; that game is left out of seed points entirely.

    Use YYYY-MM-DD dates so games sort correctly. A game entered twice (once from each team’s schedule) is counted once. Lines starting with # are ignored.

    An opponent’s win percentage counts every varsity game in the list for that team, so enter full schedules for any team that shows up as an opponent.
